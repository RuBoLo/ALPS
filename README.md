# ALPS

ALPS (**A**strophotography **L**ibrary for **P**rocessing **S**oftware) is a free ([as in freedom](https://en.wikipedia.org/wiki/Free_software)), open-source library for astrophotographic image processing.

This repository also contains AlpX (standing for ALPS executable), a command-line application built on top of the library. It is useful for testing and development, but is also intended to be useful as a standalone tool.

> Early development

## Build

Using CMake from the project root:

```sh
cmake -B build
cmake --build build
```
